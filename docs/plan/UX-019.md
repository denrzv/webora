# UX-019 plan — Branded action bouquet and Webora control sheet

Status: PLAN_APPROVED

## Overview

Replace one ambiguous `siteMenuExpanded` state with mutually exclusive `siteActionsExpanded` and
`browserMenuVisible`. Render site actions as a focusable anchored popup owned by `SiteSkinDock`.
Render browser overflow as a neutral modal bottom sheet at `BrowserScreen` root. Remove the mixed
bare drawer path.

## Flow

1. `SiteSkinChromeModel.actionBouquet()` concatenates bottom navigation, quick actions, then site
   menu; deduplicates normalized IDs; and returns at most five models.
2. Flower toggles `siteActionsExpanded` and closes browser overflow. `SiteSkinDock` anchors a
   focusable popup directly above its center hub.
3. The popup renders local icons in 52 dp alternating guarded primary/secondary circles with a
   symmetric petal lift. Selecting closes first, then dispatches the unchanged `NavigationItem`.
4. More closes the bouquet and sets `browserMenuVisible`.
5. `IntegratedBrowserMenuSheet` renders favourite plus closed browser commands as large neutral
   local-icon tiles. Close, Back, outside tap, swipe, or selection invokes `onDismiss`.
6. Page start, tab/config change, Home, and mode departure clear both states before navigation UI can
   persist.

## Origin and trust boundary

The bouquet is reachable only from the active authorized exact HTTPS integrated configuration.
Website input stops at normalized `SiteSkinItemModel`: bounded ID/label, closed semantic icon token,
active state, and typed `NavigationItem`. Guarded colour pairs are the only visual values accepted.
The browser owns cap/order/deduplication, popup focus/dismissal, circle/arc geometry, target sizes,
compiled resources, and action dispatch timing.

The Webora sheet accepts no `SiteSkinChromeModel`, configuration, brand asset, origin, or guarded
colour scheme. Its inventory is `browserMenuCommands()` plus a browser-owned favourite action. Its
palette, typography, icons, geometry, scrim, labels, and callbacks come exclusively from app
resources and `MaterialTheme`.

## Security and accessibility

- Retain closed `siteSkinIconResource`; arbitrary tokens still select only generic local fallback.
- Focus the popup and sheet so Back/outside dismissal cannot fall through to WebView/history.
- Dismiss before invoking any typed callback to prevent stale or double activation.
- Use semantic item labels and selected state on icon-only site circles; do not rely on icon meaning.
- Keep every circle/tile at least 48 dp and bound the bouquet to five at compact width.
- Use no required motion; the petal geometry communicates expansion in reduced-motion mode.
