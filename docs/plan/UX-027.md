# UX-027 plan — reproduce first, then fix what the reproduction localises

Status: PLAN_APPROVED

PRD: `docs/prd/UX-027.prd.md`
Research: `docs/research/UX-027.md`
Issue: [#128](https://github.com/denrzv/webora/issues/128)

## Overview

Research F1 closed four of the issue's five investigation sections by evidence: the artwork, the
origin, URL resolution and the loader are all fine, and the loader is textually unchanged since the
commit where this demonstrably worked. What remains is publication and Compose propagation.

Research F5 is therefore the plan's spine: **reproduce before diagnosing further.** The reproduction
is required coverage anyway (PRD criterion 1), so it is not speculative work even if it goes green.

1. **Reproduce.** Real fixture, real bytes, real loader, real guard, in the JVM gate.
2. **Fix** what that localises, with a negative control.
3. **Cover** the transition so the next regression fails on a developer machine.

The plan deliberately does **not** commit to a defect. Research narrowed it to an identity
association that is correct on paper, and naming a fix before the reproduction runs would be the
guess `/plan` exists to avoid.


## Origin and trust boundary

Unchanged, and the pressure runs the wrong way for once. Every other SiteSkin ticket pushes toward
letting a site do less; this one pushes toward publishing *more eagerly*, and the guard that would be
relaxed is the one stopping one origin's brand appearing over another's page (`HARDEN-002`,
`UX-012`).

So any change to `publishesBrandAsset` or to the configuration-identity association ships with a
control proving a **foreign** configuration still cannot publish. `NET-003`'s caps, allow-list,
signature matching, redirect limit and same-origin recheck are untouched, and `BrandAssetLoaderTest`
must pass **unedited** — if it needs editing, the fix has changed what the browser accepts rather
than how it propagates.

## Security and accessibility

- The 40 dp slot and the 52 dp hub circle stay decorative in the semantics tree. The load's outcome
  must not become an accessibility-visible property of them — `NET-004`'s rule, and the reason the
  screenshot harness reads the recorder instead.
- No new diagnostics vocabulary: `BrandAssetStage` and `BrandAssetRejection` already name every
  stage the issue's Diagnostics section lists, and the inspector already displays them.
- A failed asset must still leave the integration working. No failure path may blank the slot or
  deactivate SiteSkin.

## File-by-file plan

### TASK-1 — reproduce end to end

- **New** `app/src/test/java/app/webora/browser/siteskin/BrandAssetPipelineTest.kt`
  - Bloom's checked-in fixture through the real `SiteSkinValidator`, bound to the MockWebServer's
    origin so `logoUrl` resolves to the server.
  - The real PNG bytes from `assets/siteskin/logo.png`, served with `content-type: image/png`.
  - The real `OkHttpBrandAssetSource` and `BrandAssetLoader`, so URL resolution, the origin recheck,
    the redirect policy, the caps and the signature check are all genuinely exercised.
  - A decoder stand-in for the one call a JVM cannot make (`BitmapFactory`), which is why
    `BrandAssetDecoder` is an interface.
  - Then `publishesBrandAsset` driven with the modes a real session produces, and the published
    value read back the way a consumer reads it: `pair.takeIf { it.first === configuration }?.second`.
- If it goes green, the pipeline and the guard are sound and TASK-2 looks only at composition.
- If it goes red, it has localised the defect and TASK-2 fixes exactly that.

### TASK-2 — fix what TASK-1 localises

Deliberately unspecified. Whatever it is:
- it ships with a negative control that fails a named test when reverted;
- it does not relax `publishesBrandAsset` without a foreign-configuration control;
- it does not add a `remember` at a render site to paper over shared state (the issue warns against
  patching the centre button alone, and the drawer would stay wrong).

### TASK-3 — cover the transition

- Assert *fallback → loaded* as a state change, not merely that a loaded asset exists. The gap
  research F4 names is that both halves can be green while the transition is broken.
- Instrumented coverage for the surfaces, recorded as evidence and never promoted to a gate claim.

## Out of scope, stated so it is not re-litigated

- Reopening `NET-004`'s retry policy unless the reproduction implicates it.

- Changing Bloom's artwork or any geometry.
