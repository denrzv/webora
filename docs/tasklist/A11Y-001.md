## Pre-requisite (not an A11Y-001 task)
- [x] Repair two racy OkHttp cancellation tests that failed on `main` before this ticket began.
  - Source: baseline `bash scripts/pre-commit-check.sh` on the ticket branch, red before any change.
  - `cancelAndJoin` returns when the coroutine completes, which precedes the OkHttp dispatcher
    thread observing the cancelled call, so both tests read the flag in a race they now lose
    deterministically on JDK 21. Replaced the immediate read with a bounded `CountDownLatch.await`.
  - Negative control: removing `continuation.invokeOnCancellation { cancel() }` from
    `OkHttpManifestSource` fails `cancelling fetch cancels the underlying call`; restoring it passes.

- [x] TASK-1: Browser-owned copy and the literal convention gate

    `app/.../siteskin/SiteSkinChrome.kt`, `app/build.gradle.kts`
  - Acceptance: no browser-owned composable passes a string literal directly to `Text(`; the gate
    discovers composable sources rather than listing them, so a new screen is covered without being
    registered; the exemption set is small and each entry carries its reason inline.
  - Tests: `BrowserSurfaceConventionsTest` — `browser copy resolves from resources`,
    `accessible names resolve from resources`, `the scan actually covers the compose surface`.
    Written first; it listed nine offenders across `HomeScreen`, `OnboardingScreen`,
    `SiteSkinChrome`, and `SiteSkinTopBar` before any string moved.
  - Deviation: the catalogue and onboarding page copy were not literals inside `Text(` and so were
    not reachable by the scan. Rather than widen the regex until it guessed, `SuggestedSite` and
    `OnboardingPage` now hold `@StringRes Int`, which makes a literal a compile error there — a
    stronger guarantee than the scan could give, enforced by the type system.
  - Deviation: the third test (coverage floor) was not planned. Added because the first draft of the
    scan passed vacuously when the source root resolved to an empty set; a rule that cannot fail is
    not a rule, so the floor is asserted at 6 discovered composable sources.

    `HomeScreen.kt`, `OnboardingScreen.kt`, `PrivacySettingsScreen.kt`
  - Acceptance: `MINIMUM_TOUCH_TARGET` is at least 48 dp on both axes; browser-owned UI no longer

  - Deviation: `SiteSkinChrome` had its own private 48 dp constant from `SKIN-003`. Folded into the
    shared `MINIMUM_TOUCH_TARGET` rather than left as a second source of the same number.
