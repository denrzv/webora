# CI-010: Tasklist
Status: IMPLEMENTED_AWAITING_HOSTED_ACCEPTANCE

Issue: #115

## Accepted scope

CI-010 uses the deployed SiteSkin fixture at `https://denrzv.github.io/`.
Bloom now explicitly requests the hosted presentation it wants:

```json
"presentation": {
  "hub": "drawer",
  "dock": ["catalog", "cart", "profile"]
}
```

The hosted contract is therefore no longer inferred from `auto -> drawer`. The persistent dock must
project `catalog`, `cart`, and `profile`; the drawer must retain only the trusted actions not projected
there (`home`, `call-shop`). Explicit bouquet evidence remains deferred until a real deployed fixture
requests bouquet; Webora must not add a screenshot-only manifest override.

## Current runtime contract

- `UX-024`: the browser-owned Navigation Hub owns Back, Forward, and Refresh.
- `UX-025`: Bloom projects Catalog, Cart, and Profile into the persistent dock; projected ids are
  de-duplicated from the drawer rather than deleted from the trusted action model.
- `UX-026`: the drawer is compact/content-sized, leaves scrim available, and is dismissible via that
  scrim without dispatching a site action.
- Browser-owned Brand and More remain in the integrated dock alongside the projected site actions.
