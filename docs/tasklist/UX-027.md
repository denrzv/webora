  - Result: **done, and it does not reproduce the reported defect.** Five cases, all green:

    | Case | Result |
    |---|---|
    | Bloom's real manifest + real 512×512 PNG → `stage=DECODED`, `httpStatus=200` | PASS |
    | monogram **before**, `BitmapAsset` **after** — the transition itself | PASS |

    **What this rules out.** Combined with research F1 — artwork present, origin serving `200

    validation, decode gating, publication, or the identity association. That leaves composition, or
    the environment.

- [x] TASK-2: fix what TASK-1 localises
  - Unspecified by design — the plan refuses to name a defect before the reproduction runs.
  - Negative control mandatory; no relaxation of `publishesBrandAsset` without a foreign-configuration
    control; no `remember` at a render site to hide shared state.
  - Acceptance: PRD criteria 2, 3, 6, 7, 8, 10.
  - Result: **done.** TASK-1 could not reproduce it, and an inspector reading from the affected
    device named the cause instead — which is what `NET-004` built the inspector for.

    ```
    Produced by  TRANSPORT_UNAVAILABLE      HTTP status  —
    Load took    32863 ms                   Attempts     3
    ```

    `CALL_TIMEOUT_SECONDS` is 10 and the backoff is 1 s then 2 s, so `3 × 10 + 3 = 33 s` against the
    32 863 ms recorded: every attempt hit the full call timeout with no server answer. Meanwhile the
    manifest read `Outcome CACHED / Cache FRESH_HIT`, so SiteSkin activating was never evidence the
    network was reachable — only one of the two made a call.

    **This is `NET-004`'s defect at a longer timescale.** Its diagnosis was that a transient failure
    became permanent because *"nothing ever asked again"*; its fix added three attempts, which moved
    the boundary from 0 s to 33 and did not remove it. `retriesBrandAsset` gives the browser a later
    natural opportunity — a same-origin main-frame page start — rather than a bigger burst. Raising
    `MAX_ATTEMPTS` would move the boundary a third time and lengthen a stall the user already waits
    through.

    `NET-004`'s exclusions are unchanged and asserted by name: a rejection means the server answered,
    the same bytes decode the same way, an undeclared logo has nothing to request.

    | Control | Result |
    |---|---|
    | revert the fix — effect keys on the configuration alone | `the generation gates the load effect…` FAILED |
    | bump the generation on every page start | same case FAILED |
    | widen the decision to retry a rejection | 2 cases FAILED |

    No page start means no retry, so it cannot spin; and nothing about `publishesBrandAsset`,
    `NET-003`'s caps or the allow-list moved, so `BrandAssetLoaderTest` passes unedited.
