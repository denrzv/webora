## Tasks

- [x] TASK-1: rebuild the tab switcher as a full-window browser-owned modal
  - Replace `AlertDialog` with the `Dialog` + full-size `Surface` + `safeDrawing` structure
    `PrivacySettingsDialog` established, and split a drivable `TabSwitcherContent` out of it.
  - Replace the two filled buttons per row with a tonal selectable surface plus a sibling
    `WeboraIconButton` close control, keeping all four tag constants and the `selected` semantics.
  - Give the selected row a colour-role distinction that survives both projections; move the
    accessibility sentence off the visible label and onto the row's `contentDescription`.
  - Acceptance: PRD criteria 1–11.
  - Tests: new `TabSwitcherContractTest` (JVM, four assertions each with a negative control),
    extended `TabSwitcherTest` (instrumented), `TabSwitcherModelTest` unedited,
    `./gradlew :app:testDebugUnitTest :app:compileDebugAndroidTestKotlin`,
    `bash scripts/pre-commit-check.sh`.
  - Negative controls to run and record:
    1. collapse the selected/unselected roles onto `chrome`/`container` → the dark-projection
       assertion must fail;
    2. restore `AlertDialog(` → the full-window assertion must fail;
    3. put `TAB_SELECT_TAG` on a `WeboraButton` → the filled-affordance assertion must fail.
  - Result: the switcher is now a `Dialog(usePlatformDefaultWidth = false)` over a full-size
    `Surface`, with a headline, tonal selectable rows, a `WeboraIconButton` close control, a
    full-width `New tab` and a text `Close`. All four tag constants and both callbacks are unchanged
    and `TabSwitcherModelTest` passed unedited. `TabSwitcherContractTest` is 7/7,
    `:app:compileDebugAndroidTestKotlin` compiles, `bash scripts/pre-commit-check.sh` is green.

    Negative controls — all three run, each failed only its own assertion, all restored:
    1. selected role collapsed onto `container`/`onContainer` → `selected and unselected rows
       separate in both projections` failed, and **only on the dark projection**:
       `Actual: Color(0.12156863, 0.17254902, 0.17254902, 1.0, sRGB)`. That is the research's
       predicted failure mode reproduced exactly — the light projection passed throughout.
    2. `usePlatformDefaultWidth = true` → `the switcher is a full-window modal, not a confirmation
       box` failed. Reverting to a literal `AlertDialog(` does not compile without its import, so the
       control used the compilable half; the `AlertDialog(` half is covered by the in-test
       counter-example.
    3. `TAB_SELECT_TAG` moved onto a `WeboraButton` → `the row select affordance is not a filled
       button` failed. Note the first attempt at this control did not compile at all: `WeboraButton`
       has no `shape`/`color`/`contentColor`, so the type system rejects the regression before the
       test does. The control was rewritten to a compilable filled row to prove the *test* catches it.

    Two defects in the test itself, both found by running it rather than by reading it:
    `\$` inside a Kotlin raw string is a template, not an escape, so the select-tag regexes compiled
    to `\s` + `elect_tab_` and matched nothing in either direction; and `contains("IconButton(")`
    also matches `WeboraIconButton(`, so the raw-component check passed over the wrapper's own call.
