# CI-009: Research
Status: RESEARCH_READY

## Question
How can the existing four-frame hosted journey become complete M9 visual evidence without granting
remote content any new authority or weakening the screenshot refusal path?

## Origins involved
- `https://denrzv.github.io` is the deployed Bloom document, manifest, route, and brand-asset origin.
  Product discovery uses accessible remote text only as a black-box interaction locator. Trust still
  comes from the already-validated exact `SiteOrigin` and browser-owned Compose tags.
- `https://example.com` is the final ordinary HTTPS destination. It intentionally has no role in the
  Bloom consent/configuration and demonstrates exact-origin SiteSkin teardown.
- Local Home/onboarding and all browser chrome are app-owned; Android System UI remains a separate
  window authority inspected by `ScreenEvidenceGuard`.

## Manifest-controlled surface
No production surface changes. The deployed site continues to influence only validated bounded
SiteSkin title/subtitle, normalized colours, semantic icons, typed navigation/actions, and the
same-origin bounded brand asset. Its HTML, images, product name, and page layout paint only the
WebView content rectangle. A remote string may help UiAutomator click `Happy Days Bouquet`; it must
not decide whether an integrated frame is accepted or supply its caption.

## Browser-owned remainder
The canonical domain/TLS identity, expressive header geometry, fixed Back/Forward/hub/Tabs/More dock,
native hub section boundaries and commands, consent copy/actions, regular address/navigation chrome,
frame inventory/captions, and every capture/refusal decision remain browser- or harness-owned.

Acceptance uses stable Compose tags (`SITESKIN_SECURITY_TAG`, `EXPRESSIVE_HEADER_TAG`,
`SITESKIN_DOCK_TAG`, `SITESKIN_MENU_TAG`, `BROWSER_SECURITY_TAG`, and
`BROWSER_NAVIGATION_SHELL_TAG`) plus browser resource strings. `ScreenEvidenceGuard` then requires
Webora to own the focused window and requires rendered page pixels for every WebView-bearing frame.
The final regular frame additionally proves all integrated layers are absent.

## Risks
- Remote copy changes → only `Happy Days Bouquet` may locate the public link; all evidence predicates
  remain closed browser tags/resources, and DEMO-005's contract test pins the deployed vocabulary.
- A hub lookalike painted in the WebView → require the Compose `SITESKIN_MENU_TAG` plus browser-owned
  localized section headings and keep page rendering as a separate prerequisite.
- History races → wait for the browser-owned Back/Forward control to reach its expected enabled state
  before clicking, then reassert integrated identity/dock before every capture.
- Partial or reordered artifacts → fixed zero-padded filenames, pure source-contract assertions,
  contact-sheet marker/order tests, and the existing workflow PNG/tile comparison.
- Additional capture latency → reuse the existing 30-second live wait and render deadlines; add no
  second test journey or workflow build.
- Hosted acceptance unavailable locally → compile instrumentation and run all JVM/shell/workflow
  checks locally, then use two final cold workflow dispatches and record immutable run evidence.
