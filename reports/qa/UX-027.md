## Edge cases

- **invalid manifest → regular browser mode** — Untouched. The retry is reachable only from
  integrated mode, and a failed asset never deactivates SiteSkin.
- **origin change / redirect** — No origin decision changed. The generation is bumped only for the
  *active* tab's page start, and the existing publication guard still refuses a foreign
  configuration, so a retry cannot cross an origin. Exact-origin departure removes the asset with the
  rest of integrated chrome, unchanged.
- **offline with cached manifest** — This is precisely the reported case, and the inspector reading
  shows why it was confusing: `Cache FRESH_HIT` means the manifest made no request, so SiteSkin
  activated while the network was unreachable. The fix makes the asset recoverable on the next page
  start instead of permanently lost.
- **oversized or malformed payload** — Unchanged. `NET-003`'s 512 KiB cap, bounds-only probe,
  signature match and SVG refusal are all still enforced, and none is retried.
- **accessibility** — Unchanged. The 40 dp slot and 52 dp hub circle stay decorative; the load's
  outcome is not an accessibility-visible property of either, which is why the harness reads the
  recorder rather than the tree.

Status: QA_PASSED

Notes:

- **The reproduction passing was the finding, not a failure of it.** It excluded six layers by
  evidence and stopped the ticket shipping a composition fix for a transport defect — which is what
  the issue's own section 4 would have led to.
- **The device reading is what named the cause**, through the inspector `NET-004` built for this
  question. `32863 ms` and `Attempts 3` match `3 × 10 s + 1 s + 2 s` exactly, which is what
  identifies a blackholed connection rather than a refusal.
- **The user-visible fix is unverified here.** Whether the logo now appears on that emulator needs
  the APK on that device; this checkout has none. What is verified is that the browser will ask
  again, which is the thing that was missing.
- **`CI-009`/`CI-010` are unaffected** — no frame, tag or capture policy changed.
