## Edge cases

- invalid manifest → `Unavailable`; regular browser mode remains unchanged.
- origin change / redirect → a new observed main-frame start cancels old discovery; manifest HTTP redirects must remain on the exact original canonical origin and stop after two.
- offline with cached manifest → N/A — caching/offline reuse is reserved for `NET-002`; I/O failure falls back.
- oversized or malformed payload → actual and declared responses over 128 KiB are rejected; malformed bytes are rejected by `SiteSkinValidator`.
- accessibility (TalkBack, font scale) → N/A — no UI or accessibility semantics change; discovery results are intentionally not rendered.
- lifecycle cancellation → disposing browser composition cancels its discovery job and the underlying OkHttp call.
- runtime instrumentation/screenshots → N/A — transport/coordinator behavior is covered by JVM tests and this ticket makes no perceptible UI change.
