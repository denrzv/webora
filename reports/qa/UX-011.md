## Edge cases

- invalid manifest → regular browser mode: PASS — unchanged activation fallback; the regular shell
  accepts no configuration input.
- origin change / redirect: PASS — no origin logic change; state still comes from the active tab.
- offline with cached manifest: PASS — no cache change; ordinary fallback retains browser controls.
- oversized or malformed payload: PASS — no parser change; rejection cannot reach the shell API.
- accessibility (TalkBack, font scale): PASS for compiled names, states, 48 dp targets, compact
  bounds, and 200% cases. Runtime TalkBack inspection is unavailable without a device.
- Home/new-tab: PASS — page actions are visible/disabled; Home, Tabs, and overflow remain active.
- minimum 320 dp width: PASS — 16 dp insets leave 288 dp for six 48 dp targets.
- Android system navigation: PASS by static ownership contract — `safeDrawing` is consumed once and
  `OnBackPressedDispatcher` remains the system-Back seam. Runtime modes are environment-limited.
