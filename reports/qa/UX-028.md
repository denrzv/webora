## Edge cases

- **Invalid manifest → regular browser mode.** N/A — no validation, discovery or activation code was
  edited. The inspector *reports* a rejection and the document now carries that report:
  `InspectorJsonTest`'s rejected-record case pins `outcome: "REJECTED"`, `rejection: "HTTP_ERROR"`,
  `schemaVersion: null` and `applied: null` all serializing validly.
- **Origin change / redirect.** The document is keyed on the snapshot the panel renders, and
  `rememberInspectorSnapshot` recomputes per canonical origin. `inspectorJson` takes one parameter and
  reads nothing else, asserted from the compiled method and the declaration line. The confirmation
  flag is `remember(snapshot)`, so a stale `Copied` cannot survive onto a new origin's data.
- **Offline with cached manifest.** N/A — nothing here performs or observes transport. A
  `CACHED / FRESH_HIT` record serializes like any other; `UX-027` records why that state is easy to
  misread, and the document now carries `cacheState` explicitly rather than leaving it to a glance.
- **Oversized or malformed payload.** The *website's* payload never reaches this code — the snapshot
  holds counts, codes, pointers and bounded strings, never manifest bytes. The one arbitrary website
  string in the document is the diagnostic pointer, exercised with 400 characters carrying a
  right-to-left override and a newline: it arrives flattened and clamped to `MAX_SUBTITLE_LENGTH`,
  asserted by equality with the panel's own bound rather than by a length ceiling.
- **Accessibility (TalkBack, font scale).** The control's accessible name resolves from
  `inspector_copy_description`, the target is `WeboraOutlinedButton`'s 48 dp, and confirmation is a
  persistent node whose live region is published only when there is something to say —
  `BrowserStatusRegion`'s shape. The review found and fixed the case where a second copy said nothing.
  200% font scale is instrumented; the action pair reflows through Material's own `AlertDialogFlowRow`.
- **Release variants.** Two independent mechanisms, both exercised: the files are in `src/debug/java`,
  and `assertInspectorAbsentFromReleaseVariants` now names `InspectorJson` and `JsonDocument` beside
  the panel. Moving both files into `src/main/java` fails `release` and `debugRelease`, naming each
  class and the prefix it matched.
- **Hosted screenshot evidence.** Unaffected. `CI-009`/`CI-010`'s canonical frames do not contain the
  inspector — `DEVX-003` moved its affordance into the menus so that they would not — and this ticket
  composes nothing new outside the panel. No frame inventory, per-frame check, capture policy,
  deadline, threshold or exclusion was edited.

Notes:

- **Scenario 11 and the instrumented clipboard cases are evidence, not gate claims.** `./gradlew test`
  never runs `androidTest`, and this checkout has no emulator; what the gate proves is that they
  compile. `A11Y-001`, `CI-002`, `CI-003`, `CI-004` and `CI-005` each recorded their instrumented
  results the same way, and none of them was promoted.
- **Scenario 13 has no test and that is a deliberate limit, not an omission.** The finding is 8 dp of
  dialog height in the idle state. Asserting it needs a device, and the device suite is not the gate;
  a source scan for the absence of `spacedBy` would forbid a spelling rather than the mechanism, which
  `BROWSE-009` warns against. The persistent-node requirement it must not break *is* covered — the
  `Box` and its conditional semantics are unchanged and the instrumented announcement case still
  passes.
- **No detekt suppression and no baseline entry.** Two findings arose during implementation
  (`LongMethod` and `MaxLineLength`, both in `InspectorJsonTest`) and both were resolved by extraction
  and wrapping.
