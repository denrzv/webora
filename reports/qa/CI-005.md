— Webora owned the screen, and the page region had drawn — at the moment it was taken. Previously
only the second was checked on the returned frame.

1. A frame taken while a system dialog owns the screen is never kept.

3. A transient obstruction is retried rather than ending the run on contact.
4. The failure and the record distinguish *never rendered* from *rendered but contested*.
5. `CI-002`'s and `CI-003`'s existing guarantees are unchanged.

## Result
Status: QA_PASSED
Notes:

**Scenario 15 is the honest gap, and it is deliberate.** A green run is exactly as consistent with
"no candidate was ever rejected" as with "one was and the loop recovered". Only a `REJECTED` line in
`rendered-*.txt` separates them, and this session cannot read the artifact. Run 15's journey took
8m06s against run 14's ~6m, which is *suggestive* of retries and is **not** evidence — emulator boot
on this profile varies by minutes, and the run has no boot-time breakdown that would let the two be
distinguished.

So the claim this report supports is: **the change is not a regression, and the decision is proved by
the JVM gate.** The claim it does not support is that a contested capture has been observed to
recover on hardware. `CI-002` exists because a green run was believed once already; that lesson
applies to this ticket's own evidence.

**Scenario 7 is the control that matters.** `TASK-1` shipped with controls that fed single pairs to
a pure function — which proves the function while the defect was in *when* the function is called,
the precise mistake research risk 4 named. The sequence test was added during `TASK-2` after noticing
that, and it is the one that fails when the verdict reverts to content-decides.

**Scenario 16 passed, and it closed a product ticket as a side effect.** Run 15's frame 03 shows the
full branded bar — back control, title, subtitle, domain and TLS — so `UX-010` closes as not a
defect: run 14's missing bar was a surface captured before paint, under a dialog dimming everything.
`UX-009` reproduced on the same clean frame and therefore is *not* a paint artefact. Two findings
from one pair of frames, resolved in opposite directions.

**Scenario 10 corrects a prediction.** The plan said the second control would fail one test alone;
it fails three, because the sweep and the retry floor catch it too. Recorded as run rather than as
forecast — a tasklist that restates its prediction is how a control stops being evidence.
