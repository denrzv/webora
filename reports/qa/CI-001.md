## Edge cases

- invalid manifest → Existing validator degrades to regular mode; the final native-tag wait times out
  and uploads diagnostics rather than claiming integrated evidence.
- origin change / redirect → Existing exact-origin activation remains authoritative; a redirect away
  cannot satisfy the exact canonical consent assertion for `https://denrzv.github.io`.
- offline with cached manifest → Fresh emulator has no cache; live outage yields bounded failure and
  retained instrumentation/logcat. Cache behavior is outside this screenshot ticket.
- oversized or malformed payload → Existing bounded validation rejects it; final evidence gate fails
  closed. No parser logic changed.
- accessibility (TalkBack, font scale) → N/A — no UI behavior changed. The journey uses browser-owned
  semantics already covered by accessibility work; the screenshot device uses default font scale.
- missing screenshot directory → The workflow initializes the artifact, tolerates `adb pull` long
  enough to save logcat, then fails explicitly when PNG count is zero.
- instrumentation failure after partial capture → Partial PNGs, Gradle output, result and logcat are
  uploaded; the original Gradle exit status remains the job exit status.
