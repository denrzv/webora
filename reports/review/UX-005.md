# Review: UX-005
Date: 2026-08-13
Status: RESOLVED

## Summary
Review covered both implementation commits, the core/app trust boundary, published vocabulary,
vector resource contract, quick-action presentation, accessibility semantics, negative controls,
and repository complexity gates.

## Architecture

| Concern | Assessment |
|---|---|
| Module boundary | Semantic allow-listing remains in pure `:siteskin-core`; Android resource selection remains in `:app`. |
| Data flow | DTO string → core normalization → trusted `NavigationItem.icon` → closed browser resource map. No untrusted constructor or copy seam was added. |
| UI state | `SiteSkinChromeModel` and typed selection callbacks are unchanged; the launcher only previews `items.first()` from the existing bounded list. |
| Dependencies | Seven local vectors were added in the existing `UX-002` mechanism; no icon library or network path was introduced. |
| Complexity | Resource selection is a constant map lookup and detekt passes. |

## Security

| Property | Assessment |
|---|---|
| Manifest influence | Limited to tokens in core's explicit allow-list. Unknown/resource-like values normalize to browser-owned `generic`. |
| Resource isolation | The app uses a closed constant map to compiled ids; the source contract forbids dynamic resource, URI, file, and URL lookup. |
| Origin boundary | No discovery, origin activation, redirect, logo, or action-resolution code changed. |
| Security identity | Domain/TLS presentation and browser-owned menu inventory are untouched. |
| Failure behavior | Null and inconsistent icon values render the same local generic vector without affecting browsing or selection. |

## Findings

No open findings. No `TASK-FIX-*` work is required.

## Not findings

- **`grid_view` remains supported beside `catalog`.** It is an intentional compatibility alias for
  already-published manifests; both map to one browser-owned asset.
- **The quick-action launcher shows the first action's icon even when several actions exist.** It is
  a preview, not direct dispatch: activation still opens the complete bounded menu, and the
  browser-authored content description remains plural.
- **The trusted domain stores a string instead of an enum.** Forward-compatible schema behavior is
  intentional. The security validator is the constructor boundary, and the app still fails closed
  to the generic mapping for an internally inconsistent value.
- **The vectors declare black.** Compose `Icon` tints the complete single-color stroke with the
  current content color; the resource contract pins one color and forbids fills.
- **The Bloom Flowers fixture still spells its catalogue icon `grid_view`.** Its served bytes are
  hash-pinned across repositories; `DEMO-003` owns changing the published reference integration.
