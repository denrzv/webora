## Not findings

- **The six slot names are string constants at their private call sites.** They are test identifiers,
  not user-visible labels or a generic command registry; localized semantics still come from the
  existing string resources.
- **The overflow popup is composed beside the weighted slots.** Compose's popup anchor/layout does
  not consume a seventh visible command slot; geometry assertions measure the closed dock and the
  unchanged interaction test opens and selects the menu.
- **Fractional widths may differ at the physical-pixel boundary.** Six equal weights can round by a
  pixel; the test deliberately permits one pixel while also pinning centers and both outer edges.
- **The helper suppresses `LongParameterList`.** These parameters preserve the already-existing
  direct typed callbacks and browser-observed enabled flags; replacing them with a generic command
  payload would weaken the closed ownership boundary.
