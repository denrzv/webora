# Review: UX-003
Date: 2026-08-13
Status: RESOLVED

## Summary

The implementation preserves the committed-origin identity seam, command inventory, status region,
recovery actions and local design-token/icon boundary. One visual/structural mismatch blocks
acceptance: the floating navigation dock was composed inside the top `BrowserChrome`, above page
content, while Direction A places it below the page as a bottom dock.

## Findings

### FINDING-1 · High · ADR-013 Direction A structure
+**File:** `app/src/main/java/app/webora/browser/browser/BrowserChrome.kt`
+
+Current: `BrowserNavigationDock` is the final child of the top `BrowserChrome` column. Since
+`RegularBrowser` composes all of `BrowserChrome` before `BROWSER_CONTENT_TAG`, the dock appears below
+the identity chip and above the page. The selected design places `.a-dock` after the page/content
+frame as bottom browser chrome.
+
+Fix: make the top address/identity group and bottom dock separate app-layer components. Compose the
+dock after the page `Box` in regular mode, while retaining integrated mode's own bottom navigation
+and keeping both dock variants outside `BROWSER_CONTENT_TAG`. Strengthen the source contract to pin
+the exact `top < page < regular dock` ordering, with a broken top-dock example as negative control.
+
+## Not findings
+
+- **Reload does not become stop while loading.** The selected drawing labels the slot as
+  reload/stop, but `BrowserWebViewController` has no stop capability. A stop glyph wired to reload
+  would be a false affordance; adding a controller capability is outside this visual ticket.
+- **Disabled history icons use Material disabled treatment.** The prohibited opacity is the
+  direction's 38% treatment of *enabled, unselected* slots. A genuinely unavailable forward/back
+  action is correctly disabled in semantics and presentation.
+- **Page information remains a no-op menu dispatch.** This predates the rebuild and the shared closed
+  browser menu intentionally preserves it; the ticket does not add a page-information sheet.
+- **The error page displays a registrable domain.** It receives the bounded state projection, not a
+  document title or arbitrary manifest label.
