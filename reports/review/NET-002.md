## Not findings

- **The cache is in-memory rather than persistent.** This intentionally provides same-session offline resilience without persisting browsing history before `PRIV-001` defines clearing policy.
- **A fresh cached body is validated again.** This preserves the rule that cache possession is not trust.
- **A stale entry has no fixed stale-lifetime ceiling.** Stale bytes are used only after explicit transport unavailability, remain bounded accepted bytes, and are exact-origin revalidated; the normative 24-hour rule caps freshness.
- **`OkHttpManifestSource` still implements nullable `ManifestSource`.** The adapter preserves the core contract while cache orchestration consumes the app-only closed result.
