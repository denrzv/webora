## Not findings

- **The hub renders a website-derived bitmap in browser chrome.** This is the one bounded brand slot
  already authorized by NET-003: same-origin PNG/WebP, byte/dimension/decode caps, and an identity
  publication guard. Back/Forward/Tabs/More still accept drawable resource ids only.
- **The asset parameter is non-null.** Loading and failure are represented by the existing
  configuration-derived `BrandAsset.Monogram`, not null/zero-size UI, so geometry cannot jump.
- **`SiteSkinDock` receives `brandAsset` separately from `ExpressiveSiteSkinPresentation`.** Assets
  are deliberately absent from that color/motion projection; keeping them separate preserves
  UX-013's narrow presentation model rather than weakening it for convenience.
- **No new bottom padding constant was added to WebView.** The dock is already a measured sibling
  after a weighted content region; adding fixed padding would double-reserve space and ignore actual
  dock measurement. Outer `safeDrawing` remains consumed once.
- **The semantic icon lookup became `internal`.** It returns only compiled resource ids from a private
  closed map and exists for direct negative-control testing; it does not expose Android resources to
  core or allow remote lookup.
